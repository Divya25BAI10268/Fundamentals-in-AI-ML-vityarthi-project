#***📚 Book Recommendation System***

A simple Machine Learning based Book Recommendation System that suggests books based on user input using content-based filtering and cosine similarity.

---

***🚀 Features***

- Recommend similar books based on user choice
- Uses Natural Language Processing (NLP) techniques
- Implements CountVectorizer for text feature extraction
- Uses Cosine Similarity to find similar books
- Beginner-friendly and easy to understand

---

***🛠️ Technologies Used***

- Python 🐍
- Pandas
- Scikit-learn
- VS Code

---

***📂 Project Structure***

Book-Recommendation-System/
│── BOOK RECOMMEND.py
│── README.md

---

***⚙️ How It Works***

1. A dataset of books and genres is created
2. Text data (genres) is converted into numerical vectors using CountVectorizer
3. Cosine similarity is calculated between all books
4. Based on user input, the system recommends similar books
